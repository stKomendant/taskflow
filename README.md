# TaskFlow

A mini project-management app (users, projects, tasks, tags) built as a 
learning project to practice full-stack development.

## About this project

I'm a self-taught developer, and I'm building this project step by step 
with guidance from Claude (Anthropic's AI) to learn database design, 
authentication, testing, and deployment — the core skills I need for a 
junior full-stack role. I write the code myself; Claude explains the 
concepts and reviews what I write.

## Tech stack
- Backend: Node.js, Express, TypeScript, Prisma, PostgreSQL
- Frontend: React
